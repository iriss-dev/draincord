# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `draincord`, please send an email to Iris at `iriss.smith08@proton.me` with details regarding the issue and steps to reproduce.

Please do not open public issues regarding security vulnerabilities until they have been addressed. You will receive an initial response within 48 hours.
